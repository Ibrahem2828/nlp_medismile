# إرشادات تسمية نصوص الأعراض (مسودة — تحتاج مراجعة واعتماداً من طبيب أسنان قبل الاستخدام)

> الهدف: أن يصل طبيبان مستقلان إلى نفس التسمية لنفس النص. إذا لم تكفِ هذه الإرشادات لحالة ما، اكتب ملاحظتك في عمود `notes` ولا تخمّن.

## ماذا تُسمّي؟
لكل نص ثلاث تسميات: **التشخيص المرجّح** (`label`) و**درجة الاستعجال** (`urgency`) و**الأعلام الحمراء** (`red_flags`). سمِّ بناءً على **النص وحده** كما كان سيفعل طبيب فرز (triage) يقرأ الرسالة، لا على ما قد تجده في الفحص السريري.

## 1) التشخيص المرجّح (`label`) — اختر قيمة واحدة بالضبط
| القيمة | متى تُستخدم |
|---|---|
| `خراج سني` | قيح أو صديد أو خراج، أو تورم (لثة/خد/وجه) مع ألم، أو تورم الوجه |
| `التهاب عصب غير عكوس` | ألم مستمر أو تلقائي يزداد ليلاً أو نابض أو شديد، ولا يزول بزوال المحفّز |
| `التهاب عصب عكوس` | ألم حاد قصير مع البارد/الساخن/الحلو ويزول خلال ثوانٍ بعد زوال المحفّز |
| `تسوس عميق` | ألم عند المضغ أو الضغط أو حفرة واضحة في السن بلا أعراض الخراج أو العصب غير العكوس |
| `تسوس سطحي` | حساسية خفيفة للحلو/البارد أو بقعة/تسوس سطحي دون ألم مستمر |
| `التهاب لثة` | نزيف لثة (عند التفريش/الخيط/تلقائي) واحمرار أو التهاب لثة دون ألم سني ولا تورم خراجي |
| `غير واضح حالياً` | لا أعراض (فحص روتيني)، أو أعراض غير سنية، أو معلومات لا تكفي، أو النص منفي بالكامل |

قواعد حسم التعارض (من الأخطر إلى الأخف): خراج ← عصب غير عكوس ← عصب عكوس ← تسوس عميق ← تسوس سطحي ← التهاب لثة.
إذا ظهر عرضان من فئتين، اختر **الأخطر المدعوم بالنص**، واذكر الفئة الأخرى في `notes`.

> ملاحظة: **التهاب دواعم السن** و**حساسية الأسنان** ليستا فئتين في النظام الحالي. سمِّهما بأقرب فئة (مثلاً حساسية حرارية → `التهاب عصب عكوس` أو `تسوس سطحي`) واكتب في `notes` التسمية التي كنت ستستخدمها، فنقرر لاحقاً إن كان يجب إضافتها.

## 2) الاستعجال (`urgency`)
- `Urgent`: يحتاج تقييماً خلال 24 ساعة (خراج، التهاب عصب غير عكوس، أي علم أحمر).
- `Non-Urgent`: يمكن حجز موعد عادي.
عند الشك بين الاثنين اختر `Urgent` واكتب السبب في `notes`.

## 3) الأعلام الحمراء (`red_flags`) — اكتب الرموز مفصولة بـ `;` أو اتركه فارغاً
| الرمز | المعنى |
|---|---|
| `fever_with_swelling_or_pus` | حرارة/حمى مع تورم أو قيح |
| `trismus` | صعوبة فتح الفم |
| `dysphagia` | صعوبة البلع |
| `breathing_difficulty` | صعوبة أو ضيق في التنفس |
| `uncontrolled_bleeding` | نزيف لا يتوقف أو غزير |
| `trauma` | رضّ، ضربة، سقوط، حادث، كسر |
| `spreading_facial_swelling` | تورم يمتد للوجه/العين/الرقبة/تحت الفك |
أي علم أحمر يجعل `urgency = Urgent` حتماً.

## 4) النفي والسياق
- العرض المنفي **غير موجود**: «بدون تورم ولا قيح» ليست خراجاً؛ «ما في ألم» ليست ألماً.
- النفي ينتهي عند «بس/لكن» أو في الجملة التالية: «ما في تورم بس ألم شديد» ← الألم موجود.
- احكم على **الحالة الحالية** لا التاريخية: «كان عندي خراج وعولج» ليست خراجاً الآن.
- النص الذي يصف شخصاً آخر (طفل، أم) يُسمّى كما لو كان المريض.

## 5) أمثلة محلولة
| النص | label | urgency | red_flags |
|---|---|---|---|
| ألم شديد مستمر يوقظني من النوم | التهاب عصب غير عكوس | Urgent | |
| عندي تورم وألم | خراج سني | Urgent | |
| بدون ورم ولا قيح وعندي ألم عند المضغ | تسوس عميق | Non-Urgent | |
| ألم لحظي مع البارد ثم يزول | التهاب عصب عكوس | Non-Urgent | |
| نزيف في اللثة عند التفريش | التهاب لثة | Non-Urgent | |
| أريد فحصاً روتينياً ولا يوجد ألم | غير واضح حالياً | Non-Urgent | |
| صعوبة في البلع وألم في السن | غير واضح حالياً | Urgent | dysphagia |
| حرارة وتورم في الخد | خراج سني | Urgent | fever_with_swelling_or_pus |

## 6) إجراءات الجودة
- لا تناقش الحالات مع المُعلِّم الآخر قبل إنهاء تسمياتك.
- إذا تجاوزت نسبة «غير واضح» 40% من تسمياتك فراجع نفسك: غالباً أنت تتحفّظ أكثر من اللازم.
- لا تنسخ التسميات من أي مخرجات للنموذج: ذلك يفسد التقييم.
- كل النصوص يجب أن تكون **مجهولة الهوية** (بلا أسماء أو أرقام هواتف أو معرّفات).
